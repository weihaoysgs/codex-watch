Codex Watch selects the Idle, Walk, Run and Jump PNG sequences, scales them using
a common canvas and baseline, and assembles horizontal atlases. No original art
authorship is claimed. Conversion script: packaging/prepare_pets.py (build only).
All sprites are bundled locally; rendering requires no downloads or API calls.

The original asset pack does not contain laundry, fish-eating or mouse-chasing
scenes. Version 0.5.0 adds app-authored Qt scene choreography, articulated body
poses and vector props (wash tub, cloth, fish, bone, mouse, ball, yarn, frisbee)
in native/pet_scenes.py, composed with the CC0 character art. These additions
are not represented as original pzUH animations or third-party downloads.
